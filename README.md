# Mitsuki Apps

A GitHub Pages hub for Mitsuki's learning apps.

## Structure

- `index.html` — app selection/home screen
- `math/index.html` — Magical Math Garden

## GitHub Pages

Enable Pages from **Settings → Pages → Deploy from a branch → main → / (root)**.

The home page will be:
`https://red00013.github.io/mitsuki/`

The math game is linked automatically from the home page.
