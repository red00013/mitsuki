# Mitsuki's Magical Math Garden

A kid-friendly single-digit addition and subtraction practice game.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

The site is completely self-contained and does not require external libraries.
